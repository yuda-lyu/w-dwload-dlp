(async) WDwloadDlp(url, fp, optopt) → {Promise}

Description:

  • 下載video檔案，預設轉mp4，核心調用yt-dlp，只能用於Windows作業系統

    yt-dlp: https://github.com/yt-dlp/yt-dlp

    yt-dlp.exe與ffmpeg.exe不含於npm包，首次調用時經ensureBins依清單之SHA-256與大小校驗後取得(快取、鏡像或GitHub)，安裝時不下載； 部署前可預先調用WDwloadDlp.ensureBins()(yt-dlp.exe)與WFfmpeg.ensureBins()(ffmpeg.exe，見w-ffmpeg)， 離線與內網之用法(W_BIN_CACHE、W_BIN_MIRROR、W_BIN_OFFLINE)見README〈外部執行檔〉； 每次調用在作業系統暫存夾(os.tmpdir())下之w-dwload-dlp夾內，以時間加隨機id命名專用之工作夾內作業(下載、合併、轉檔之中介檔皆在其內)，結束時(成功或失敗)刪除該夾，結果檔複製到fp， 故多個調用可併行互不影響，不寫執行檔所在夾，也不切換工作路徑；每次調用開始時另刪除w-dwload-dlp/下修改時間逾24小時之殘留工作夾(行程崩潰或被強制結束所遺)

(async) dwloadSubtitle(url, optopt) → {Promise}

Description:

  • 下載字幕(不下載影片)，核心調用yt-dlp，只能用於Windows作業系統，目前支援提供json3字幕軌之網站(YouTube)，不需瀏覽器與登入，也不需ffmpeg.exe

    先取得影片資訊與字幕軌清單，依語言偏好挑選1軌後，再由yt-dlp下載該軌之json3字幕並解析；挑選規則見pickSubTrack： 有手動字幕時只從手動字幕挑(任何語言之手動字幕皆優先於自動字幕)，否則從自動字幕挑，自動字幕中語言相符者先取非機器翻譯者

    yt-dlp.exe之取得、工作夾之建立與刪除皆與WDwloadDlp相同，併行調用互不影響；結果不寫檔，由呼叫端自行處理； 與WDwloadDlp相同不設整體逾時：yt-dlp預設20秒無回應即放棄，但對方持續少量送出資料時可能無限等待，需要時請由呼叫端自行設定逾時； YouTube對字幕下載會限流(HTTP 429，機器翻譯軌尤甚)，本函數不重試，reject為httpError，訊息含原文

ensureBins(optopt) → {Promise}

Description:

  • 取得本套件之外部執行檔yt-dlp.exe: 首次使用時自GitHub主幹(master)下載(或自鏡像取得)，以清單之SHA-256與大小校驗，之後自快取取得(亦校驗)

    本套件為主幹模式(mode為floating)：執行時先取GitHub主幹之bin/manifest.json，取不到或無效時用npm包內同路徑之基準清單， 故yt-dlp.exe更新只須推GitHub，不須發布本套件(見README〈外部執行檔〉)

    規格: 外部執行檔之存放下載校驗與離線(制式規格)§6; 實作為wsemi之fsEnsureBins, 本套件不另寫下載、快取、鏡像、校驗 環境變數: W_BIN_CACHE、W_BIN_MIRROR、W_BIN_OFFLINE, 見README〈外部執行檔〉

parseDlpError(stderr, optopt) → {String}

Description:

  • 由yt-dlp之stderr提取錯誤並分類，組成調用方易讀之錯誤訊息

    回傳字串首行固定為[代碼] 說明與處置，供調用方判斷錯誤類型，次行起依序為下載進度(有fragment資訊時)、yt-dlp之ERROR原文、WARNING原文(去重後最多3行)

    代碼可為unsupportedUrl、unavailable、sslFailed、dnsFailed、connectFailed、http403、http404、httpError，有ERROR但不屬前述者為dlpFailed，無任何ERROR者為execFailed

parseSubJson3(str) → {Array}

Description:

  • 解析yt-dlp下載之json3字幕檔內容為字幕段落

    json3結構為{ events: [{ tStartMs, segs: [{ utf8 }] }] }，無segs之event為視窗定義；自動字幕之換行event其segs僅含空白，兩者皆略過； event之tStartMs缺漏或非有效數字時，沿用前一段落之tMs(首段為0)，使段落之tMs不遞減；不去除連續相同之文字，其為字幕本身(例如重複之[音樂])

pickSubTrack(info, langs) → {Object}

Description:

  • 由yt-dlp之影片資訊挑選要下載之字幕軌

    只考慮有json3格式之字幕軌；有手動字幕時只從手動字幕挑(任何語言之手動字幕皆優先於自動字幕)，否則從自動字幕挑； 依langs之順序挑選，語言代碼大小寫不分，同一語言先比完全相同再比語言前綴；自動字幕中語言相符者先取非機器翻譯者(原文軌與原文語言)，再取機器翻譯者，皆不符時取原文軌，無原文軌時取清單第1筆
